# Money Journal

A mobile app to track personal finances.

## Getting Started

### Prerequisites
- Node.js
- React Native CLI
- Firebase account

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/money-journal.git
   cd money-journal
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure Firebase by setting up your project in the Firebase console.
4. Replace the Firebase configuration in `FirebaseConfig.js`.
5. Run the app:
   ```bash
   npx react-native run-android
   # or
   npx react-native run-ios
