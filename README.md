# Tiny Guestbook

## Project Setup

1. Clone the repository:
   ```bash
   git clone <repository_url>
   cd tiny-guestbook
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build the project for production:
   ```bash
   npm run build
   ```

5. Deploy to Vercel:
   ```bash
   vercel
   ```
