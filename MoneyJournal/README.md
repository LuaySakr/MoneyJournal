# Money Journal

## Project Setup

1. **Clone the repository**: `git clone <repo-url>`
2. **Install dependencies**: Navigate to the MoneyJournal directory and run `npm install`
3. **Setup Firebase**: Follow Firebase setup instructions and create a project.
4. **Configure Environment Variables**: Copy `.env.example` to `.env` and set your Firebase credentials.
5. **Run the app**: Use `npx react-native run-android` or `npx react-native run-ios` to start the app.
